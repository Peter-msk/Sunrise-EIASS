# Sunrise EIASS

**최신 배포 기준: v4.6.1** · Windows 10/11 x64 · 단일 실행파일(EXE)

환경영향평가정보지원시스템(EIASS)에 공개된 사업과 문서를 검색·열람·다운로드하는 Windows 업무지원 프로그램입니다.

## 1. 프로그램 개요
Sunrise EIASS는 환경영향평가 관련 사업을 검색하고 사업개요, 사업위치, 평가 단계별 공개 문서를 한 작업공간에서 검토하도록 지원합니다. EIASS 운영기관의 공식 프로그램이 아닌 Sunrise Group의 독립적인 업무지원 도구입니다.

## 2. 개발 목적
- 사업명과 업무 조건을 이용한 반복 검색 과정을 단순화합니다.
- 사업개요부터 문서 열람·다운로드까지 연결된 업무 흐름을 제공합니다.
- 평가구분·기관·사업유형에 따른 검색 결과를 구분하여 검토 편의성을 높입니다.
- 많은 문서를 다룰 때 진행상태와 처리 결과를 확인할 수 있도록 합니다.

## 3. 주요 기능
- 전략환경영향평가, 환경영향평가, 소규모환경영향평가, 사후환경영향조사 등 사업 검색
- 사업명·키워드, 평가구분·협의기관·사업유형별 조건 검색
- 사업개요, 위치, 평가 단계별 공개 원문 목록 확인
- PDF 미리보기, 본문 검색, 확대·축소 및 페이지 보기
- 선택 문서 또는 여러 문서 다운로드, 중지·재개·실패 항목 재시도
- 지도에서 사업 위치 확인
- 공지사항과 버전 확인

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 배포 형식 | Windows 단일 실행파일 |
| 네트워크 | EIASS 검색·문서 열람 및 지도 기능에 인터넷 연결 필요 |
| 추가 조건 | EIASS 공개 범위와 외부 서비스 상태에 따라 조회 결과가 달라질 수 있음 |
| Python 설치 | 배포 EXE 실행에는 필요 없음 |

## 5. 설치 및 사용방법
1. [공식 릴리즈](https://github.com/Peter-msk/Sunrise-EIASS/releases)에서 해당 버전의 실행파일을 내려받아 실행합니다.
2. 사업명 또는 검색 키워드를 입력합니다.
3. 평가구분, 협의기관, 사업유형 등의 조건을 선택하고 **검색**을 실행합니다.
4. 검색 결과에서 사업을 선택해 사업개요와 원문 목록을 확인합니다.
5. **PDF 보기** 또는 다운로드 기능으로 필요한 문서를 검토·저장합니다.
6. 필요한 경우 지도에서 사업 위치를 확인합니다.

비공개 사업, 아직 공개되지 않은 문서, 외부 서비스 제한에 해당하는 자료는 조회되지 않을 수 있습니다.
