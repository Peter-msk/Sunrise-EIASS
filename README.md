# Sunrise EIASS

Sunrise Group이 개발한 환경영향평가정보지원시스템(EIASS) 공개자료 검색·열람 도구입니다. EIASS 운영기관의 공식 소프트웨어는 아닙니다.

## 프로그램 목적

환경영향평가 사업을 다양한 조건으로 검색하고, 공개된 사업개요·평가 문서·위치정보를 확인하여 환경영향평가 자료 조사와 문서 검토 업무를 효율화합니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)
- EIASS 검색·문서 조회·지도 기능 사용 시 인터넷 연결이 필요합니다.

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** EIASS 공개자료 조회, PDF 문서 처리 및 Windows 데스크톱 UI
- **배포 형태:** 단일 Windows 실행파일(EXE)

## 주요 기능

- 전략·환경·소규모 환경영향평가 및 사후환경영향조사 사업 검색
- 사업명, 키워드, 평가구분, 협의기관, 사업유형별 조건 검색
- 사업개요, 위치 및 단계별 공개 문서 목록 확인
- PDF 미리보기, 본문 검색, 확대·축소 및 페이지 탐색
- 개별·다중 문서 다운로드와 중단·재개·실패 항목 재시도
- 지도 기반 사업 위치 확인
- 장시간 검색·다운로드 진행상태 및 결과 표시
