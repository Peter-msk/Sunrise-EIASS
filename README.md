# Sunrise EIASS

> EIASS 환경영향평가 사업을 검색하고, 사업개요와 원문 문서를 한 화면에서 확인할 수 있도록 만든 Windows 업무지원 프로그램입니다.

## 프로그램 소개

**Sunrise EIASS**는 환경영향평가 실무자가 EIASS에 공개된 사업자료를 보다 빠르고 편리하게 확인할 수 있도록 제작된 프로그램입니다.

사업명이나 관련 키워드로 평가사업을 검색하고, 평가유형별 검색결과와 사업개요를 확인한 뒤 초안·본안·보완·변경협의·사후환경영향조사 등의 원문 문서를 열람하거나 다운로드할 수 있습니다.

여러 EIASS 화면을 반복해서 이동하지 않고, 검색부터 원문 검토까지 하나의 작업 흐름으로 처리하는 것을 목표로 합니다.

## 주요 기능

- 전략환경영향평가, 환경영향평가, 소규모환경영향평가, 사후환경영향조사, 사전환경성검토 사업 검색
- 사업명 및 관련 항목 검색
- 평가구분, 협의기관, 사업구분 조건 설정
- 평가유형별 검색결과 구분
- 사업개요 및 사업위치 확인
- 초안·본안·보완·변경협의 등 원문 문서 분류
- PDF 원문 미리보기와 본문 검색
- 마우스 휠 페이지 이동 및 `Ctrl + 마우스 휠` 확대·축소
- 한쪽 보기와 고정 두쪽 모아보기
- 선택 문서 또는 전체 문서 다운로드
- 다운로드 일시중지, 재개, 중지 및 실패 문서 재시도
- 네이버지도를 이용한 사업위치 확인
- 도로사업의 시점·종점 주소 개별 확인
- 공지사항 및 새 버전 업데이트 확인

## 기본 사용 방법

1. 사업명 또는 검색할 키워드를 입력합니다.
2. 평가구분, 협의기관, 사업구분 등의 조건을 선택합니다.
3. **검색** 버튼을 눌러 사업목록을 확인합니다.
4. 원하는 사업을 선택해 사업개요와 원문 문서 목록을 확인합니다.
5. **PDF 보기**로 문서를 검토하거나 필요한 원문을 다운로드합니다.
6. 사업위치는 네이버지도에서 확인할 수 있습니다.

## 이용 안내

Sunrise EIASS는 EIASS 운영기관이 제공하는 공식 프로그램이 아니라, 공개된 EIASS 자료를 실무에서 보다 편리하게 확인하기 위해 제작된 독립적인 업무지원 도구입니다.

EIASS의 서비스 상태, 공개 범위, 비공개 정책, 서버 응답 또는 화면 구조에 따라 일부 사업이나 원문이 조회되지 않을 수 있습니다. 진행 중이거나 비공개로 관리되는 사업의 원문은 열람 또는 다운로드가 제한될 수 있습니다.
