Sunrise EIASS v4.3.7

개선된 기능
- 좌측 검색 패널에서 진행현황을 직접 선택
- 일반 평가: 전체·완료·진행중
- 사후환경영향조사: 전체·승인완료·정보입력중·검토중·정보반려
- 서버 필터 응답을 목록 상태와 교차검증하고 모호한 경우에만 상세 확인

기존 기능 유지
- 협의기관 정확도, 다중 파일명 다운로드, PDF 미리보기, 업데이트 안정화 유지
- Windows 파일 잠금 재시도와 업데이트 롤백·정리 기능 유지

앞으로의 개발
- EIASS 내부 검색 계약 변경 시 평가유형별 파라미터와 HTML 파서를 독립 갱신

배포 확인
- Windows onefile 실빌드와 실제 EIASS 상태별 검색 smoke 후 배포
